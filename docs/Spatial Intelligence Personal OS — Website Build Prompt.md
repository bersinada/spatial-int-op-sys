# 2. PRODUCT PHILOSOPHY

The application should feel like a calm, intelligent command center.

It should NOT feel like:

- a corporate project-management dashboard
- a complicated Notion clone
- a gamified productivity app
- a noisy task manager
- a social media feed

It should feel like:

> “This is the control room for the professional I am becoming.”

The interface should create clarity rather than stimulation.

Prioritize:

- visual hierarchy
- whitespace
- typography
- hierarchy of importance
- minimal cognitive load
- elegant information architecture
- subtle motion
- strong progress visualization
- meaningful data
- calm visual language

Avoid unnecessary cards, badges, gradients, animations, charts, or decorative UI.

# 3. DESIGN DIRECTION

Visual style:

- minimal
- modern
- premium
- editorial
- technical
- intelligent
- calm
- slightly futuristic
- restrained

Think:

- Linear
- Vercel
- Arc
- modern developer tools
- high-end personal operating systems
- technical research dashboards

Do NOT make it look like a typical SaaS admin panel.

Color palette:

- warm white / off-white background
- near-black text
- subtle gray borders
- muted secondary text
- restrained accent color, preferably electric/technical blue
- optional very subtle green for completed/progress states

Keep contrast strong.

Do not use excessive gradients.

Use thin borders and subtle shadows.

Typography should feel sophisticated and highly readable.

Use a clean modern sans-serif such as Inter, Geist, or equivalent.

Too much planning, not enough execution.

Too many unrelated technologies.

### Tutorial addiction

Consuming content instead of building.

### Portfolio inflation

Creating many shallow projects.

### Visibility procrastination

Waiting until work is “perfect” before publishing.

### Startup premature optimization

Trying to invent a startup before finding a real problem.

### Local career tunnel vision

Optimizing only for the Turkish job market.

### Technology hype

Learning tools without understanding the underlying problem.

The product should help me notice these patterns.
