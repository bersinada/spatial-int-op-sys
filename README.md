# Spatial Intelligence OS

A local-first personal Career & Founder Operating System for becoming a Spatial Intelligence Engineer — built with React, TypeScript, Vite, and Tailwind CSS.

The full product specification lives in [`docs/Spatial Intelligence Personal OS — Website Build Prompt.md`](./docs/Spatial%20Intelligence%20Personal%20OS%20%E2%80%94%20Website%20Build%20Prompt.md).

## Sections

Dashboard, Roadmap, Monthly Focus, Projects, Writing, Open Source, Network, Problem Radar, Skills, Reviews, Knowledge, and Settings — plus secondary utility views (Daily, Clarity Mode, Decision Support, Founder Mode, Global Positioning) reachable from Settings or the command palette (`⌘K`).

## Data

Everything is stored locally in the browser (no backend, no auth). Export/import a full JSON backup from Settings.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # typecheck + production build
npm run lint     # oxlint
```
